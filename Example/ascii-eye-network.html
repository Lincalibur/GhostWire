SIGNAL_ARRAY

A network of watching eyes wired into a central node. Move your cursor near any of them.

// About this effect

The center node is an ASCII skull built from a masked shape (blurred for soft edges) filled with binary characters, with a slow breathing pulse. Each surrounding eye is the same AsciiEye component from before — recolored red/black, with a black pupil hole — and each one tracks the cursor independently once it gets close.

The wires between the center and each eye are drawn entirely in characters too — no vector strokes. A pulse travels along each trace on a loop, and every character's color sweeps from near-black up to bright red as the pulse passes through it, like current moving through a live board. A handful of extra tendrils wander out from the center on random paths that never land on an eye — restless "searching" lines that fade and regenerate elsewhere over time.

To switch the center node back to a plain eye instead of the skull, find const CENTER_TYPE = 'skull' near the bottom of the script and change it to 'eye'. Node positions live in the NODE_LAYOUT array if you want to rearrange the network — x/y are percentages of the hero section.
